# Создание приложения с Kafka

Приложение разбито на модули producer и consumer.


Перед началом работы запустить файл docker-compose.yaml в каталоге docker. 
Kafka запускается на трех брокерах, каждая партиция дублируется на 2 реплики.

В папке producer запустить метод main в классе ProducerApp.
Будет создано 100 записей экземпляров класса Person в топике my-topic. 
Конфигурационный файл для producer расположен в классе KafkaConfig.

Модуль consumer содержит классы SingleMessageConsumer для обработки каждой записи
и BatchMessageConsumer для работы с пакетами по 10 записей.

Для обработки данных в отдельных потоках используется ExecutorService.

Результаты работы приложения выводятся на экран.

В интерфейсе kafka-ui статус consumer должен быть STABLE, поле Lag устанавливается в количество записей добавленных 
producer, затем снижается до 0 после обработки consumer.
